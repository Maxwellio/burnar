# Цветовая маркировка строк наряда

## Цель

Перенести цветовую маркировку строк из Delphi-форм `CommonNarZadUnit` и
`CommonNarVipUnit` на веб-страницу наряда. Задание и выполнение получают
собственные кнопки установки и сброса цвета на своих панелях действий.

## Исходное поведение

Delphi открывает `TColorDialog`, записывает выбранный `TColor` в `colorsel`
выбранной строки и после операции снимает выделение. Сброс устанавливает `0`
только выбранной строке. Действия недоступны без выбранной строки и в закрытой
части наряда.

Цвет хранится в Delphi BGR-представлении: например, красный равен `255`, а не
CSS RGB `16711680`. Значение `0` зарезервировано как отсутствие маркировки,
поэтому чёрный фон выбрать нельзя.

## Данные и API

Миграция не требуется: `burnar.zadanie_oper.colorsel` и
`burnar.vipolnenie_oper.colorsel` имеют тип `numeric NOT NULL DEFAULT 0`.
Деревья уже возвращают `colorsel`.

Добавляются операции:

- `PATCH /api/naryady/{id}/zadanie/{nodeId}/color`;
- `PATCH /api/naryady/{id}/vipolnenie/{nodeId}/color`.

Тело запроса: `{ "color": number }`, где допустимы целые значения
`0..16777215`. Сервер проверяет доступ к наряду, принадлежность строки указанной
части и открытое состояние соответствующего описателя. `0` выполняет сброс.
Успех возвращает обновлённые `nodeId` и `color`.

Заголовок карточки дополнительно возвращает `zadanieClosed` и
`vipolnenieClosed`. Отсутствующая часть считается недоступной, а серверная
проверка остаётся обязательной независимо от состояния кнопок.

## Интерфейс

Пустая панель действий внутри каждой вкладки получает свою пару кнопок:

- «Выделить строку цветом» открывает палитру образцов и пункт «Свой цвет»;
- «Свой цвет» — видимое поле, которое пользователь нажимает сам. Палитра не
  закрывается, пока открыт системный селектор. Промежуточный оттенок сразу
  виден на строке и сохраняется по мере выбора;
- «Сбросить цвет» записывает `0`.

Кнопки относятся только к дереву своей вкладки. Сейчас поддерживается ровно
одна выбранная строка. После успешной операции таблица локально обновляет фон
и снимает только синюю подсветку, чтобы цвет был виден. Выбранный узел,
параметры и алгоритм остаются: цвет можно подбирать повторно, не выбирая
строку заново. Дерево не перечитывается и не сворачивается. При ошибке выбор и
прежний цвет сохраняются, пользователю показывается сообщение.

Синяя интерактивная подсветка выбранной строки имеет приоритет над сохранённым
цветом, пока строка подсвечена. После снятия подсветки становится виден
сохранённый фон. Цвет применяется при первоначальной и ленивой загрузке узлов
через преобразование BGR в CSS RGB.

`BaseTreeTable` получает только необязательные возможности: вычислить фон строки
и сбросить внутреннее выделение по сигналу. Без новых props поведение остальных
таблиц не меняется. Изменение фиксируется в staging-копии
`mainComponent-changes/BaseTable/BaseTreeTable.tsx` для переноса в соседний
пакет `mainComponent`.

## Совместимость

Выбранный браузером `#RRGGBB` преобразуется в Delphi BGR перед сохранением.
Полученное из БД BGR-число преобразуется обратно в CSS `#RRGGBB`. Это сохраняет
правильное отображение исторических цветов и совместимость новых значений с
Delphi.

## Ошибки и конкурентность

Backend не доверяет переданным идентификаторам и ограничивает обновление
одновременно `narkey` и `key`. Закрытая часть возвращает конфликт, отсутствующая
или чужая строка — `404`, некорректный цвет — `400`. Локальное состояние
меняется только после успешного ответа.

## Проверка

- unit-тесты преобразований RGB/BGR и вычисления фона;
- backend-тесты диапазона цвета, выбора таблицы, принадлежности строки и запрета
  закрытого наряда;
- frontend build и backend test suite;
- ручная проверка задания и выполнения: существующий цвет, установка цвета,
  сохранение после повторного открытия, сброс и недоступность в закрытой части.

## Будущее расширение

Множественный выбор не входит в текущую задачу. Следующий этап может добавить
`Ctrl/Cmd + клик` для изменения набора и `Shift + клик` для диапазона. Тогда API
можно расширить пакетной операцией со списком `nodeIds`; текущий однострочный
контракт остаётся корректным.
